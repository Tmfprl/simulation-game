# 🎮 Bung-o-pong  

시뮬레이션 게임 제작 프로젝트 **Bung-o-pong**에 오신 것을 환영합니다.  
이 게임은 **Ren'Py 엔진**을 활용하여 파이썬 기반으로 개발되었으며,  
2024년 6월에 제작되었습니다.  

본 프로젝트는 **Come2us 대회 출품작**으로 개발되었으며, 일부 이미지의 저작권은 **Come2us**에 귀속됩니다.

## 💻 실행 방법
## 실행 방법

`Bung_O_Pang-1.0-dists` 폴더 안에는 운영체제별 게임 실행 파일이 압축된 형태로 제공됩니다.  
자신의 운영체제에 맞는 압축 파일을 선택하여 해제한 뒤, 생성된 폴더 내의 실행 파일을 실행하면 됩니다.

### Windows
1. `Bung_O_Pang-1.0-pc.zip` 파일을 압축 해제합니다.  
2. 생성된 폴더 안에서 `Bung_O_Pang.exe` 파일을 실행합니다.  

### macOS
1. `Bung_O_Pang-1.0-mac.zip` 파일을 압축 해제합니다.  
2. 생성된 폴더 안에서 `Bung_O_Pang.app` 파일을 실행합니다.
